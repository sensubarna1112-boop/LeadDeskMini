# LeadDesk Mini

A full-stack Lead Management application built with React, Node.js, Express, and MongoDB.

## Features

- Public Lead Form
- JWT Admin Login
- Search Leads
- Status Update
- MongoDB Database
- Responsive UI

## Tech Stack

- React
- Node.js
- Express
- MongoDB Atlas
- JWT
- Vercel
- Render
